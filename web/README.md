# MŠ Bulharská 62 — Web

Web mateřské školy Bulharská 62, Brno.

## Struktura

```
/
├── index.html          # Hlavní stránka
├── netlify.toml        # Konfigurace Netlify (cache)
├── fonts/              # Fonty (Fraunces, Nunito)
└── images/             # Obrázky (hero, třídy, zahrada)
```

## Aktualizace obsahu

Aktuality a texty se spravují přes Google Sheets:
- List `aktuality` — příspěvky pro rodiče
- List `nastaveni` — texty a hodnoty na webu

## Deploy

Web je nasazen na Netlify a automaticky se aktualizuje při každém push na GitHub.
